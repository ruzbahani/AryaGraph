# About AryaGraph

AryaGraph is a Python library for graph and DAG visualization, analysis and simulation. It brings a graph model,
layout engines, a static and interactive renderer, graph algorithms, simulation engines and analytical reports
together in one package whose only runtime dependency is numpy.
