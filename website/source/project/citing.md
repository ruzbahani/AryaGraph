# Citing AryaGraph

If AryaGraph contributes to published work, please cite it. AryaGraph is archived on
[Zenodo](https://zenodo.org), which assigns it a permanent DOI.

[![DOI 10.5281/zenodo.22928604](https://zenodo.org/badge/DOI/10.5281/zenodo.22928604.svg)](https://doi.org/10.5281/zenodo.22928604)

## Which DOI to use

| DOI | Refers to | Use it when |
|---|---|---|
| [10.5281/zenodo.22928604](https://doi.org/10.5281/zenodo.22928604) | All versions (resolves to the latest release) | You cite AryaGraph in general |
| [10.5281/zenodo.22928895](https://doi.org/10.5281/zenodo.22928895) | Version 0.1.0 | You need to identify the exact version you used |

`aryagraph.__version__` reports the version you have installed.

## BibTeX

```bibtex
@software{mohammadi_ruzbahani_aryagraph,
  author    = {Mohammadi Ruzbahani, Ali},
  title     = {{AryaGraph}: graph and {DAG} visualization, analysis and simulation for {Python}},
  year      = {2026},
  publisher = {Zenodo},
  doi       = {10.5281/zenodo.22928604},
  url       = {https://doi.org/10.5281/zenodo.22928604},
  license   = {MIT}
}
```

To cite version 0.1.0 specifically, add `version = {0.1.0}` and use `doi = {10.5281/zenodo.22928895}`.

## APA

Mohammadi Ruzbahani, A. (2026). *AryaGraph: Graph and DAG visualization, analysis and simulation for Python*
[Computer software]. Zenodo. https://doi.org/10.5281/zenodo.22928604

## Other formats

The repository includes a [`CITATION.cff`](https://github.com/ruzbahani/AryaGraph/blob/main/CITATION.cff) file, so
the **Cite this repository** button on [GitHub](https://github.com/ruzbahani/AryaGraph) produces APA and BibTeX
entries, and the [Zenodo record](https://doi.org/10.5281/zenodo.22928604) exports further formats (for example
CSL-JSON, DataCite and EndNote).
